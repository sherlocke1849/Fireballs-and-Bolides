# Fireballs-and-Bolides
R analysis of data pertaining to recorded fireballs and bolides, as accessed from data.gov

10/20/2026: monthly:yearly.R is the first step of the analysis which uses the lubridcate function to report the monthly incidents totals and the yearly incident totals. The ggplot2 function was also used to create bar charts. Next, correlation analysis on incident count and month/season will be done, more aesthetic charts will be made, and a table will also be made.
