# Fireballs-and-Bolides
R analysis of data pertaining to the brightest/most significant recorded fireballs and bolides from 2009-2015, as accessed from data.gov

10/20/2026: monthly:yearly.R is the first step of the analysis which uses the lubridcate function to report the monthly incidents totals and the yearly incident totals. The ggplot2 function was also used to create bar charts. Eventually, correlation analysis on incident count and month/season will be done, more aesthetic charts will be made, and a table will also be made.
